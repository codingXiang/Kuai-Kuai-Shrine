## 📜 乖乖三大不可侵犯鐵律

1. **必須是綠色（奶油椰子味）**：綠色代表綠燈正常（Status OK），嚴禁使用黃色（五香/當機警示）或紅色（重大故障）。
2. **絕對不能拆開吃掉**：拆封會使守護結界破裂，伺服器可能隨即噴出 500 Internal Server Error。
3. **必須在有效期限內**：過期法力會衰退（本數位版本永久保固、永不過期）。
